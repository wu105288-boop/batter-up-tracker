# Diamond Stats Tracker

你可以做一款app幫我統計我們打棒球的數據統計嗎，可以建立使用者，然後選擇玩投手打者之後就可以開始打席輸入好壞球，或是其他結果像是安打接殺保送，打席結束後默認投手不會更換，接著統計基本資訊像是era，被打擊率之類的，跟打者如打擊率的資料這樣l，然後要有壘包圖，根據打席結果推演，二壘安打就是一壘的跑到三壘這樣算就好。但是可以手動修改，然後所有數據點進去之後都要有依照時間的變化圖，然後也可以自訂義計算的時間，要記得數據包含BAA/























IP (Innings Pitched) 投球局數:投手在場 上製造的出局數紀錄。每製造3個出局數 為1局(若抓到1或2個出局數後退場, 會記為.1 局或.2 局)。







BF (Batters Faced) 面對打席:投手交手過 的打者總人次。







NP (Number of Pitches) 總投球數:投手 在比賽中累積投出的球數總和 ／三振保送比／好壞球比例還有最重要的防禦率，如果沒有投完整局使用歷史數據推估，沒歷史數據就簡易計算



還有其他的也可以



打者就打擊率跟上壘率還有ops等等，不需要數據越全越好
